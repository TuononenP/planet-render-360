# Landmark Statue Meshes (`assets/statues/`)

Normalized, smooth-shaded, UV-mapped binary `.glb` statue meshes loaded by `SculptureKit` and merged directly into `LandmarkMesh` surfaces (so each landmark keeps its calibrated `LandmarkMaterials` bronze/marble/gilt PBR and `LandmarkShader` weathering).
