# Reference photos — san_francisco

Comparison references for `tools/capture_presets.gd` (SF hero pass, `.agents/plans/2026-11-03-san-francisco-hero.md`):
its contact sheet puts the first file beside the render, and `stats.json` flags frames whose luma, saturation or
colourfulness fall outside the range of these photos. Note the weather and season of each photo when reading those
flags: the renders are captured in clear summer conditions (03 is the foggy look, for the marine layer).

Downscaled to 640 px wide from the Wikimedia Commons originals; each keeps its licence.
The photos are not committed (`visual-plan/refs/**/*.jpg` is gitignored): download each from
its Commons page below, scale it to 640 px wide and save it under the listed file name.
